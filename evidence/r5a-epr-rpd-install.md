# EPR Packaging Data Pipeline Install (RPD deadline 1 Oct 2026)
Category: R5 deadline-radar | Status: R5-generated 2026-07-10

## R1 Spec
- Offer: 10-day automation install that turns a brand's product catalogue into submission-ready EPR packaging data: component-level packaging weight model built from Shopify/ERP/product data, material classification mapping, RPD-format CSV generation, half-yearly submission runbook, and a 1 Oct deadline checklist (incl. the new mandatory self-managed waste data). Re-runs itself every reporting period.
- Buyer: Ops/finance leads at UK DTC and wholesale brands that are EPR "large producers" (>£2M turnover, >50t packaging) — currently hand-building spreadsheets each cycle; secondary: automation practitioners in founder's audience who install it for their e-com clients.
- Price: £899 fixed install (+£199/period re-run option). Stripe.
- Channel to first 10: @theoperator audience (automation practitioners serving DTC brands — resale motion) + founder Skool + r/shopify and UK DTC operator LinkedIn communities. £0 spend.
- Timing (verified): Large producers must report 1 Jan–30 Jun 2026 packaging data by 1 October 2026 via Defra's Report Packaging Data (RPD) portal (twice-yearly cycle: 1 Apr and 1 Oct); 2026 adds mandatory self-managed organisation waste data. Under 3 months out.
- Pass-pattern followed: (2) done-for-you automation install into the buyer's existing stack (Shopify/ERP) at a recurring hard deadline — the data PRODUCTION is the pain, not the portal.
- Kill-checks run: compliance schemes (Valpak/Beyondly/Ecoveritas) submit FOR members but still require the member to produce the data — and their data-build consultancy is bespoke-priced; gov guidance free but scattered across multiple gov.uk pages; no SEO-established "EPR data pipeline install" product; incumbents predate nothing here — the automation is founder craft.

## R2 Timing Gate — PASS (verified 2026-07-10)
- Deadline verified: large producers must submit 1 Jan–30 Jun packaging data by 1 Oct via the Report Packaging Data (RPD) service; Jul–Dec data by 1 Apr the following year (recurring twice-yearly cycle). Source: https://www.gov.uk/guidance/packaging-data-check-reporting-periods-and-submission-deadlines + https://www.gov.uk/government/collections/extended-producer-responsibility-for-packaging-report-packaging-data
- 2026-specific: Jan–Jun 2026 data incl. NEW mandatory self-managed organisation waste data due 1 Oct 2026 — confirmed by 2026 practitioner guides: https://www.thefirstmile.co.uk/the-big-picture/epr-2026-reporting-requirements , https://erp-recycling.org/uk/news-and-events/2026/04/uk-packaging-epr-compliance-guide-for-2026/ ; large-producer thresholds (>£2m turnover, >50t) per https://erp-recycling.org/uk/who-are-you/packaging-epr-for-large-producers/
- Fees are now real money: 2025 base fees published (https://www.gov.uk/government/publications/extended-producer-responsibility-for-packaging-2025-base-fees/extended-producer-responsibility-for-packaging-2025-base-fees); year-1 invoices issued from Oct 2025 for the Apr 2025–Mar 2026 assessment year (https://www.gov.uk/government/news/preparing-for-pepr-year-1-invoicing-key-information-for-liable-producers); 2026/27 fees will be MODULATED (1.2x escalating to 2.0x) calculated from reported packaging data (https://assets.publishing.service.gov.uk/media/68a599d29dc94e840696a3a6/Packaging_Extended_Producer_Responsibility__pEPR__Producer_Disposal_Fees_Modulation_Statement.pdf) — so data quality now directly moves invoice size. Candidate's timing claims match the record exactly; ~12 weeks to deadline at gate date.
- Hostile caveat (noted, not killing): recurring twice-yearly cycle means no one-time cliff — large producers have already filed ~5 prior periods since 2023, so this is a routinized chore, not first-time panic.

## R3 Saturation Gate — score 8/10, KILL
- The R1 kill-check conclusion ("schemes require the member to produce the data; their data-build consultancy is bespoke-priced") is REFUTED on the decisive point: compliance schemes SELL the data production as a bundled member service.
  - Valpak (largest UK scheme, by Reconomy): members can "fully outsource data collection and submission to Valpak's Data Management Team"; expert review of data before submission and a named contact for classification questions; Insights Platform sits on a 65M+ SKU packaging dataset. https://www.valpak.co.uk/compliance/packaging-compliance/ , https://www.valpak.co.uk/insights/insight-platform/ , https://www.valpak.co.uk/how-to-collect-packaging-data-epr-guide/
  - Beyondly (fka Comply Direct): dedicated "Packaging EPR Data Management UK" service — team "can pick up as much or as little as you need, thoroughly collecting, managing, and analysing your data." https://www.beyond.ly/services/data-management/
  - Ecosurety: "Ecosurety Collect" supplier packaging-data collection platform, used by the biggest UK producers. https://www.ecosurety.com/data-services/
- Pure-play EPR data vendor owns the hard part: Ecoveritas (my.ecoveritas software + services: Data Collection, Data Calculation) solves MISSING COMPONENT WEIGHTS by applying verified sample weights from a 3M+ SKU database ("100% coverage"); clients incl. eBay, Selfridges, Claire's, New Look. This is exactly the "component-level packaging weight model" the £899 install claims to conjure from Shopify/ERP fields — incumbents solve it with reference data a solo installer doesn't have. https://www.ecoveritas.com/services/data-calculation , https://www.ecoveritas.com/services/data-collection , https://www.ecoveritas.com/powerful-epr-software
- Low end bracketed by Shopify apps: Ceendesis EPR Compliance (define packaging specs w/ material/weight/recycled content, auto-track orders, export regulator-ready CSVs — UK pEPR/RPD coverage not explicitly confirmed, HMRC PPT/LUCID/CITEO/US/Canada are) and EPR Insights (country-specific EPR data files from Shopify order + packaging data). https://apps.shopify.com/veloxlink-erp-compliance , https://ceendesis.com/compliance/erp-packaging-compliance , https://apps.shopify.com/epr-insights ; plus free consultancy content teaching DIY setup: https://eprcompliance.co.uk/blog/how-to-set-up-packaging-data-collection/
- Structural problem: every buyer in the ICP (>50t large producer) is already inside a scheme's billing relationship, and the scheme's included-as-standard support (named expert contact, pre-submission data review) or paid data-management add-on is the default path. £899 outsider install is bracketed: app-store pricing below, scheme/Ecoveritas trust + reference-weight databases above. Bespoke pricing of incumbent consultancy is not an opening — it is evidence the category is owned. Score 8/10 > 6 → KILL-R3.
