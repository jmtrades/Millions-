## R4 Red Team
Strongest failure case: unbounded scope on other people's spaghetti under a hard 48h fix-or-refund, solo. Real 2025-26 breakage classes are NOT patchable failing-paths: n8n V2 migration breakage requires node migration/partial rebuild ("Unrecognized node type: n8n-nodes-base.executeCommand", Dec 2025 — https://community.n8n.io/t/workflow-stopped-after-updating-my-n8n-to-v2-problem-running-workflow-unrecognized-node-type-n8n-nodes-base-executecommand/234260) and instance-level catastrophe is disaster recovery, not a fix ("I lost 50 production workflows overnight... zero warning, logs, or backup", Mar 2026 — https://community.n8n.io/t/i-lost-50-production-workflows-overnight/282026). Platform events (V2 wave, API deprecations) arrive as correlated spikes that break a one-person 48h queue → refund cascade after labor is already spent. Compounding: a DFY fix needs WRITE credentials to production (n8n + connected CRM/payments) handed to a stranger from a reel — the market leader in this exact buyer set leads with "read-only... your production is safe" (https://administrate.dev/features), evidence that access anxiety is a first-order objection; the R1 spec's "read-only credentials" intake cannot deliver a fix.
Strongest rebuttal: scope is contractually boundable — one workflow, failing path only; triage from read-only exports/execution logs BEFORE capturing payment (authorize-don't-capture), decline or requote rebuild-class/DR-class jobs before the 48h clock starts ("within 48h of access" per spec). Worst case is capped at £349/job = known CAC, not tail risk. The $10/1-day Fiverr tier existing at all (https://www.fiverr.com/michaeljordank/fix-n8n-workflow-errors-bugs-failed-triggers-and-automation-issues-fast) proves the modal breakage (expired OAuth, changed API field, missing error branch — per https://hackceleration.com/n8n-troubleshooting) is small for an elite operator. Trust asymmetry inverts vs anonymous sellers: public @theoperator identity + refund-backed prepay + read-only-diagnose-first, write-access-only-on-scoped-fix.
Defensible: TRUE — the attack is real but operationally boundable with triage gating and per-unit capped downside; no structural moat though (any certified partner could clone the offer), so this is a brand/craft-defended wedge, not a durable company.
