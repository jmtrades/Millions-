## R1 Spec
- Offer: Fixed-fee install that makes one WooCommerce (or BigCommerce/headless) store agent-buyable: ACP plugin installed & configured on the EXISTING store (zero migration), product feed brought to spec, Stripe Agentic Commerce Suite wired, OpenAI merchant application submitted, llms.txt/agent-readability pass, and a test agentic transaction proven. 5-day delivery, async onboarding (access form + product CSV); no call.
- Buyer: WooCommerce / BigCommerce merchant (DTC store owner) watching Shopify competitors appear inside ChatGPT by default.
- Price: £449 one-time per store, prepaid Stripe checkout (application-declined = 50% refund); £29/mo feed-health monitor upsell.
- Channel_first10 (£0): founder-crafted cold email (his core craft, owned infra) to a FRESH scraped list of ~300 Woo DTC stores (BuiltWith/store-locator scraping — explicitly not the 692K liability list) + @theoperator before/after case study.
- Timing_hypothesis: Shopify activated agentic storefronts by default for 2M+ eligible US stores on 11 Mar 2026 and OpenAI's docs confirm Shopify/Etsy catalogs are integrated "no additional setup required" — non-Shopify merchants are now competitively excluded from the fastest-growing checkout surface unless someone assembles plugin + feed + Stripe ACS + application for them. ≤12mo, dated.
- Pass-pattern: (2) done-for-you install of new capability into the merchant's EXISTING stack at a platform shift (zero migration) + (6) fix at a moment of hard competitive breakage.
- Kill-pattern clearance: K3 — the plugin is free but the assembly is not push-button: feed spec compliance, OpenAI merchant application, Stripe ACS config and agentic-transaction testing across a bespoke Woo stack (this is the classic paid-Woo-setup economy). K1 — Woo core/BigCommerce ship no default syndication (only Shopify does — that was the pass-1 kill boundary). K2 — free plugin ≠ working, approved, tested integration for a non-technical merchant. K6 — direct service, first £ = one merchant.
